## ⚠️ 当前遗留问题与待办任务


### 3. 后端路由与服务层模块解耦 (架构遗留)
- **现状**：目前绝大多数 API 接口（好感度、模型切换、知识库同步等）均写在 `routers/chat.py` 中。斜杠指令（如 `/上课`）主要依靠前端硬编码拦截。
- **待办**：
  - 在 `routers` 下抽离出 `memory.py`、`ragflow.py`、`course.py` 专用路由。
  - 在 `services` 层建立 `slash_handler.py` 来处理不同斜杠命令对应的后端真实逻辑分发。

### 4. 课程系统与授课流控 (中优先级，第三阶段)
- **现状**：当输入 `/计划` 或 `/上课` 时，仅前端模拟了一条系统回复文本，后端并无实际课程状态切换。
- **待办**：基于 SQLite 的 `course_progress` 表，实现基于学习进度的课程大纲动态生成，并在特定命令下切入真正的"考核模式"。

### 5. UI 主题自定义拓展 (低优先级，第四阶段)
- **现状**：仅有一套在 `index.css` 内死磕的深色主题。
- **待办**：建立 `src/themes` 支持 UI 换肤自定义功能。
