## 待确认细节 (Open Questions)

1. **整体布局是侧边栏还是顶栏下拉抽屉？**
   您最早提到“界面做成与导师与大纲状态的侧边栏显示逻辑一致吧”，但刚才又说“不要右侧滑入，三个子窗口都是上方滑入就行”。
   - **方案A（现在的浮窗改进版）**：界面**没有**常驻的右侧边栏。所有的状态、UI设置、API设置，都是在点击顶部的按钮后，像“抽屉”一样从屏幕正上方（或右上角）平滑向下展开覆盖在聊天记录上。
   - **方案B（移动端滑入方向改变）**：在电脑大屏幕上，它依然是一个固定在**最右侧**的常驻侧边栏，只是在**手机/小屏幕**状态下隐藏时，点击按钮后，这个面板是“从屏幕顶部往下掉”滑出来，而不是“从屏幕右侧向左挤”滑出来。
   - **方案C（侧边栏内部的下拉切换）**：不管电脑还是手机，整体是一个常驻在右侧的面板，但在点击顶部这三个按钮切换选项卡时，面板里的内容是用“从上往下滑动进入”的动画来切换（类似折叠面板的手风琴动画）。

   这三种效果您偏向哪一种？（我个人感觉如果是全局下拉抽屉（方案A），会遮挡很多聊天记录；如果是方案B或C，可能更符合“侧边栏”的定义）。
