# 媚吻锋随身课堂 (MeiWenfeng Classroom)

这是一个完全独立于 SillyTavern 的本地 Web 角色扮演与教学应用。项目主要采用 Python (FastAPI) 作为后端，React 作为前端构建，旨在通过将“好感度”、“课程进度”、“记忆管理”从 LLM Prompt 中剥离并结构化存储到本地 SQLite 中，实现极端的 Token 压缩和更高效的 RAG（检索增强生成）系统。

## 项目架构

- **后端 (`/backend`)**: 基于 FastAPI 构建。负责多模型路由接入、对话上下文管理、基于 ChromaDB/RAGFlow 的记忆衰减与归档、本地数据库交互。
- **前端 (`/frontend`)**: 基于 React + Vanilla CSS，采用深色主题的三栏式 IDE 布局（左侧文件树，中间对话/授课区，右侧状态面板）。
- **数据库 (`classroom.db`)**: 本地 SQLite 存储聊天历史、课程进度和用户系统设定。
- **知识库 (RAG)**: 包含本地轻量化向量库 ChromaDB（默认），也支持接入外部 RAGFlow 容器实例。

## 核心功能与亮点

- **流式对话与动作渲染**: 稳定连接本地或云端大模型，内嵌角色设定。特有的对话渲染系统会自动将动作描写（如 `*我推开你的书本*`）处理为斜体灰色文字展示。
- **动态记忆管理与时间线重构**: 内置本地 ChromaDB，具备自动衰减记忆日志的算法（遗忘曲线算法），可定期清理并沉淀长期记忆。
- **三栏 IDE 界面与本地挂载**: 将当前开发工作区与 AI 对话无缝结合，在应用内即可查看项目文件结构与配置状况。
- **多模型支持**: 支持 DeepSeek, Claude, Gemini 以及本地部署的 Ollama / llama.cpp，支持一键热切换。
- **内置数据监控大屏**: 前端自带可视化面板，可随时查询 SQLite 中的隐式数据和记忆日志。

## 如何启动

本项目为纯本地服务，提供了便捷的一键启动脚本：

1. 确保安装了 Python 和 Node.js 环境。
2. 确保项目根目录下存在 `.env` 文件（如果没有，复制 `.env.example` 并填入你的 API Key）。
3. 确保根目录存在合法的 Python 虚拟环境 `.venv`，并已安装 `backend/requirements.txt` 内所需的库。
4. **双击运行 `start.bat`**。
5. 脚本将自动启动后端服务（端口 8000）和前端开发服务器，并可以通过浏览器访问 `http://localhost:5173/`。
